ℹ️ How the AI works

Your profile is converted into text features using TF-IDF (Term Frequency–Inverse Document Frequency). The system compares your profile text with each scheme's description using cosine similarity, and ranks schemes by how textually close they are to your profile. Separately, simple rule checks compare your state, crop, category, land size and irrigation directly against each scheme's stated criteria — that's what powers the "why this scheme" list on every card.
